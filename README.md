# Types & Shadows

*The Bible is the original hypertext.*

An interactive map of the Bible's types, shadows and cross-references, inspired by
[Chris Harrison's BibleViz](https://www.chrisharrison.net/index.php/Visualizations/BibleViz).

- **Types & Shadows**: curated connections the New Testament makes itself, drawn as colored arcs. Click one to read the Old Testament shadow next to its New Testament substance.
- **Every cross-reference**: about 300,000 community-ranked cross-references from OpenBible.info. Hover any arc, click any chapter to read, click any verse to see where it connects.
- **Book view**: pick a book (or click its name under the map) to see each chapter flow into the books it connects to. Click a chapter to read, a line to jump to that connection, or a book to explore it next.
- **Selected connection**: click any cross-reference in the reader and it lights up in gold on the map, in both views.
- **Choose your translation**: BSB, KJV, ASV, YLT and Darby (all public domain).

## Run it

```bash
npm install
npm run dev      # http://localhost:3568, downloads the Bible data on first run
```

Live at **https://typesandshadows.app**.

```bash
npm run verify   # check every curated reference against the text, writes REVIEW.md
```

## The accuracy rule

Nothing is added to `src/data/typology.json` unless a New Testament verse makes the connection itself.
Each entry names that verse as its `anchor`. Entries fall into three tiers:

| Tier | Meaning |
|---|---|
| Named | The NT uses figurative language: type, shadow, copy, antitype, allegory, figure |
| Stated | The NT draws the connection directly, by name or by quotation |
| Fulfilled | The NT quotes the passage and says it was fulfilled, or applies it to Christ |

Popular types the NT never states (Joseph, Boaz, Rahab's cord) are left out on purpose.

To review the list, run `npm run verify`. It checks every reference against the text and writes
`REVIEW.md`, which prints each entry's passages in full so a reviewer can confirm the link is in the text.
